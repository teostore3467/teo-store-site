TEO STORE — UI repair package
الأساس: TEO_STORE_Integration_Full_Project.zip
- شعارات الدفع: object-contain بدل القص، وتصحيح معاينة الفوتر.
- نسخ الرابط وبيانات الدفع والتسليم: دالة مشتركة مع fallback ورسالة خطأ.
- الحساب: فصل الإحالات والاشتراكات إلى أقسام مستقلة، الحفاظ على الطلبات والولاء والدعم والأمان.
- الرئيسية: عرض الحملات من RPC الجديدة مع دعم الإعدادات السابقة، وتحسين التخطيط والفوتر.
- الشريط: يعرض الرسائل النشطة والنشاط المجمع الذي تعيده قاعدة البيانات، ولا يختلق طلبات.
- الشريط لا يظهر إذا كان معطلا أو لا توجد بيانات مؤهلة. في ADMIN > Marketing > Affichage public فعّل ticker_enabled أو purchase_activity_enabled حسب الحاجة. أضف رسالة حقيقية للاختبار في Messages défilants. لا تستخدم طلبات وهمية كإعلانات.
- لا تغييرات SQL، لا تفعيل للدفع الجديد، ولا حذف بيانات.
- اختبار الصياغة البرمجية: 66 ملف TS/TSX دون أخطاء صياغة. تعذر npm ci بسبب عدم توفر الحزم في cache. لم يتم اختبار البناء أو المتصفح أو Supabase فعليا.
- لا تزال وظائف المحفظة والمكافآت والدفع الجديد بحاجة لاستكمال واختبار، وهذه الحزمة ليست اعتماد إطلاق نهائي.
التركيب: احتفظ بنسخة احتياطية وبملفات .env و.git وpublic المحلية. ادمج محتويات الأرشيف. npm.cmd ci ثم npm.cmd run build ثم npm.cmd run dev. اختبر محليا قبل git push.
